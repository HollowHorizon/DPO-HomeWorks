# Kotlin classloader isolation

В JVM-проектах с конфликтами зависимостей можно изолировать runtime в отдельном ClassLoader. Child-first ClassLoader позволяет сначала искать классы в собственном jar, а затем делегировать загрузку родителю. Для безопасного взаимодействия между загрузчиками обычно выносят общие интерфейсы в bridge-модуль, загружаемый родительским ClassLoader.
