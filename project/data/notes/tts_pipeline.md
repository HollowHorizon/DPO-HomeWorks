# TTS pipeline

Пайплайн генерации аудиокниги может включать очистку текста, разбиение на фрагменты, нормализацию чисел и сокращений, генерацию аудио через TTS-модель, сохранение аудиофайлов и сборку итоговой дорожки. Для длинных книг важно сохранять промежуточное состояние, чтобы можно было продолжить обработку после ошибки.
