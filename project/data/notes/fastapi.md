# FastAPI service

FastAPI используется для создания HTTP API. Для проверки состояния сервиса обычно добавляют endpoint `/health`, который возвращает статус приложения и информацию о загруженных артефактах. Endpoint `/predict` принимает входные данные, валидирует их через Pydantic-схемы и вызывает модель. Для запуска удобно использовать uvicorn.
