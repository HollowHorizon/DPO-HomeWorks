# Docker

Dockerfile описывает контейнер приложения. Для Python-сервиса обычно используется базовый образ `python:3.11-slim`, рабочая директория `/app`, установка зависимостей из `requirements.txt` и запуск `uvicorn`. В `.dockerignore` стоит исключить виртуальное окружение, кеши, большие данные и временные файлы.
