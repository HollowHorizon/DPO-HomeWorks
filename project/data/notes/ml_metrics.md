# ML metrics

Для классификации можно использовать accuracy, precision, recall и F1-score. Для поиска документов часто применяются Precision@K, Recall@K и MRR. Baseline-модель помогает сравнить, действительно ли более сложное решение улучшает качество. В отчёте важно показать не только финальную метрику, но и обоснование выбора модели.
