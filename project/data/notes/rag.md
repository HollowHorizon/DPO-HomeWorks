# RAG

Retrieval-Augmented Generation состоит из двух основных этапов: retrieval и generation. На этапе retrieval система находит релевантные фрагменты документов по запросу пользователя. На этапе generation языковая модель формирует ответ с учётом найденного контекста. В учебном проекте генерацию можно заменить extractive-ответом из найденных чанков.
